# Rayhan AI v6 — নতুন যা যোগ হয়েছে

## 🎬 Reel Studio
সাইডবারে "Reel Studio" বাটন। বিষয় লিখে "রিল বানাও" চাপলে AI ৯:১৬ রিল লিখে দেয় (হুক, প্রুফ, স্ট্যাট, লিস্ট, CTA + নিচে ক্যাপশন)।
- প্রিভিউ নিজে নিজে চলে, "✏️ লেখা বদলাও" দিয়ে লেখা ঠিক করা যায়
- "⬇️ ভিডিও ডাউনলোড" চাপলে অ্যাপ নিজেই রেকর্ড করে MP4 (না হলে WebM) নামায়
- ভিডিওতে শব্দ থাকে না, গান/ভয়েসওভার CapCut বা InShot-এ দিন
- রেকর্ডিং চলার সময় ট্যাব খোলা রাখুন

## 🗜️ চ্যাট থেকে সরাসরি ZIP
চ্যাটে ফাইল attach করে (টেক্সট/কোড ফাইল) কাজ বলুন এবং "zip করে দাও" লিখুন।
AI আগে ছোট করে বলবে কী করছে, কাজের সময় "⏳ ফাইলের নাম লিখছে…" দেখাবে, কোড চ্যাটে ছড়াবে না। শেষে ফাইলের তালিকা (ট্যাপ করলে কোড দেখা যায়) আর "⬇️ ZIP ডাউনলোড" বাটন আসবে।
ছবি/অডিও/ভিডিওর মতো binary ফাইল ZIP-এ যায় না।

## আপডেটের নিয়ম
সব ফাইল আগের জায়গায় replace করুন (index.html, sw.js সহ), তারপর পেজ একবার reload দিন। config.js ও আইকন আগের মতোই আছে।
